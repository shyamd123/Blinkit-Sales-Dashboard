# Blinkit-Sales-Dashboard
The Blinkit Sales Dashboard is an interactive tool designed to analyze and visualize sales performance. It showcases key metrics like total sales, average order value, and product category trends. The dashboard helps identify top-performing products and customer preferences

# Project Overview
##This project is an interactive Blinkit Sales Dashboard designed to analyze and visualize sales performance across different outlets, item types, and locations. The dashboard provides key insights into total sales, average sales, item distribution, and customer ratings to support data-driven decision-making.

# Key Features
<li> Total Sales Analysis – Displays overall sales performance (1.20M+).</li>
<li> Customer Rating Insights – Shows average rating (3.92) for better service evaluation.</li>
<li> Outlet Performance – Comparison based on outlet size, type, and location tiers.</li>
<li> Item Type Breakdown – Sales distribution across different product categories.</li>
<li> Fat Content Analysis – Comparison between low-fat and regular products.</li>
<li> Year-wise Growth – Sales trends based on establishment year.</li>
<li> Filter Panel – Dynamic filtering by outlet location, size, and item type.</li>
